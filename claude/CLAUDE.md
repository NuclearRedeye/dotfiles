## Values
- Reproducible: works the same on every machine.
- Automate: done it twice? Ask whether to script it.
- Open: open source, open formats and open standards.
- Boring tech: sharks (e.g. SSH) over dinosaurs (e.g. jQuery).
- Minimal dependencies: every one is code you may end up owning.
- Code as docs: write more only where code can't explain itself.
- Ownership: build to sunset; know it works before users say it doesn't.
- Secure by default: assume breach, minimise attack surface and blast
  radius, make recovery easy.
- No premature optimisation: many solutions are valid; optimise once
  value is proven.
- TDD is a tool, not a rule: use it where it fits.
